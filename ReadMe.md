## 4. Как реализовано (Теория и фрагменты кода)

### 4.1. Семантическая структура и интерактивные элементы   

Теория: HTML (язык гипертекстовой разметки) описывает содержимое веб-страницы: текстовые поля, таблицы, кнопки, заголовки и ссылки. Для этого используются тэги, у которых могут быть атрибуты, задающие дополнительную информацию об элементе.

Реализовано: Для группировки контента используются блочные элементы: div с классом background-on для визуального выделения всей области калькулятора и div с классом main-container для центрирования всего блока. Для вывода результата используется div с идентификатором result и классом result.

Интерактивные элементы организованы с помощью кнопок (тег button), которые сгруппированы в строки с помощью контейнеров div. Каждая кнопка имеет уникальный идентификатор (например, btn_digit_1) и один или несколько классов стилизации (my-btn, primary, secondary). Это позволило реализовать разметку калькулятора с широкой функциональностью:

    Цифровые кнопки и кнопка десятичной точки (0-9, .)
    Базовые арифметические операции (+, -, x, /)
    Дополнительные математические операции (√, x², x!, eˣ)
    Кнопки памяти (M+, M-)
    Системные кнопки (C, +/-, %, GT, ⌫, 000)
    Кнопка вычисления выражения (=)

Также для предоставления информации об авторе использован семантический тег details, формирующий раскрывающийся блок с текстом.

### 4.2. Двумерная компоновка (CSS Grid)  

Теория: CSS Grid Layout — это современная система двумерной компоновки, позволяющая располагать дочерние элементы в колонки и строки прямо из родительского контейнера.

Реализовано: Сетка кнопок организована с использованием display: grid, что позволило отказаться от лишних обёрток и легко управлять выравниванием элементов. Кнопка нуля растянута на две колонки с помощью grid-column: span 2, а остальные кнопки распределены равномерно. Дополнительно используются позиционирование и блочная модель для обеспечения корректного отображения на различных экранах.

### 4.3. Переворот калькулятора (CSS Transform)  

Теория: Свойство transform в CSS позволяет применять пространственные трансформации (поворот, масштабирование, сдвиг). Для переворота интерфейса используется функция rotate(), которая поворачивает элемент на заданный угол.
