3. Задание

Разработать статический макет веб-интерфейса инженерного калькулятора. Необходимо реализовать структуру DOM-дерева с использованием HTML и визуальное оформление с применением CSS. Макет должен включать широкий набор кнопок для вычислений (включая операции памяти, вычисление факториала, квадратного корня и другие) и дисплей вывода.

Проект должен содержать следующие файлы:

    calculator.html — основной HTML-файл

    calc.js — файл с JavaScript-логикой (в процессе разработки, на момент анализа не реализован)

4. Как реализовано (Теория и фрагменты кода)
4.1. Семантическая структура и интерактивные элементы

Теория: HTML (язык гипертекстовой разметки) описывает содержимое веб-страницы: текстовые поля, таблицы, кнопки, заголовки и ссылки. Для этого используются тэги, у которых могут быть атрибуты, задающие дополнительную информацию об элементе.

Реализовано: Для группировки контента используются блочные элементы: div с классом background-on для визуального выделения всей области калькулятора и div с классом main-container для центрирования всего блока. Для вывода результата используется div с идентификатором result и классом result.

Интерактивные элементы организованы с помощью кнопок (тег button), которые сгруппированы в строки с помощью контейнеров div. Каждая кнопка имеет уникальный идентификатор (например, btn_digit_1) и один или несколько классов стилизации (my-btn, primary, secondary). Это позволило реализовать разметку калькулятора с широкой функциональностью:

    Цифровые кнопки и кнопка десятичной точки (0-9, .)

    Базовые арифметические операции (+, -, x, /)

    Дополнительные математические операции (√, x², x!, eˣ)

    Кнопки памяти (M+, M-)

    Системные кнопки (C, +/-, %, GT, ⌫, 000)

    Кнопка вычисления выражения (=)

Также для предоставления информации об авторе использован семантический тег details, формирующий раскрывающийся блок с текстом.
4.2. Стилизация с помощью CSS и основы компоновки

Теория: CSS (каскадные таблицы стилей) описывает внешний вид элементов HTML. Стили могут быть заданы через селекторы по тегу, классу или идентификатору, а затем применены к документу несколькими способами. Наиболее предпочтительный вариант — вынесение стилей в отдельный .css файл и его подключение в секции head.

Реализовано: Стилизация выполнена в отдельном файле style.css, который подключается к calculator.html. Основная сетка реализована с помощью позиционирования и блочной модели. Классы .my-btn, .primary, .secondary и .long задают единый стиль для всех кнопок:
css

.my-btn {
    margin-right: 5px; margin-top: 5px; width: 50px; height: 50px;
    border-radius: 5px; border: none; background: #2b2f33; color: white;
    font-size: 1.5rem; font-family: 'Franklin Gothic Medium', 'Arial Narrow', Arial, sans-serif;
    font-weight: 900; cursor: pointer; user-select: none;
}
/* При наведении курсора */
.my-btn:hover { background: greenyellow; }
/* При нажатии */
.my-btn:active { filter: brightness(130%); }
/* Кнопки первостепенных операций */
.my-btn.primary { background: #233cc8; }
/* Кнопки второстепенных операций */
.my-btn.secondary { background: #1ac16b; }
/* Расширенная кнопка (= и ⌫) */
.my-btn.long { width: 110px; border-radius: 5px; }
```[reference:7]

Для поля вывода результата задан отдельный класс `.result`, определяющий его размеры, цвет фона, выравнивание текста и шрифт.[reference:8]

### 4.3. Динамическое изменение темы (CSS классы и JS)

**Теория:** Для реализации динамического изменения стилей на стороне клиента используется JavaScript. С помощью свойства `classList` элемента и методов `toggle/add/remove` можно добавлять или удалять CSS-классы, переопределяющие стили.

**Реализовано:** Реализованы две функции для изменения внешнего вида:

1.  **Смена цветовой темы:** Кнопка с идентификатором `theme-button` переключает класс `dark-theme` у элемента `body`. В CSS этот класс меняет цвет фона страницы на черный (`#000000`), а цвет текста — на белый (`#ffffff`).[reference:9][reference:10]
2.  **Смена цвета окна результата:** Кнопка с идентификатором `result-theme-button`, предположительно, должна переключать класс у блока `.result`, изменяя цвет текста и фона на черный и белый соответственно.[reference:11][reference:12]
