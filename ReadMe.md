## 3. Задание

Разработать статический макет веб-интерфейса калькулятора, адаптированного под индивидуальную предметную область. Необходимо реализовать структуру DOM-дерева с использованием HTML и визуальное оформление с применением CSS. Макет должен включать базовый набор кнопок для вычислений и дисплей вывода.

## 4. Как реализовано (Теория и фрагменты кода)

### 4.1. Семантическая структура и формы

**Теория:** Семантический HTML вводит теги, которые четко описывают свое предназначение. Для реализации предметной области были использованы формы и интерактивные элементы. В частности, тег `<summary>` используется для создания нативного раскрывающегося списка с информацией об авторе, а тег `<div>` обеспечивает компоновку элементов.

**Фрагмент кода (Разметка интерактивных элементов в HTML):**

```html
<details class="student-details">
    <summary>Информация об авторе</summary>
    <p>ФИО: Гаранин Ерофей Дмитриевич</p>
    <p>Группа: ИУ5-42Б</p>
</details>

<div class="portal-services">
    <label for="services">Раздел портала:</label>
    <select id="services" class="bmstu-select">
        <option>Приказы ректора</option>
        <option>Услуги - подразделения МГТУ</option>
        <option>Заявки - приказы ректора</option>
    </select>
</div>
```

### 4.2. Двумерная компоновка (CSS Grid)

**Теория:** CSS Grid Layout — это современная система двумерной компоновки, позволяющая располагать дочерние элементы в колонки и строки прямо из родительского контейнера. Для сетки кнопок калькулятора был использован `display: grid`. Это позволило разместить все кнопки равномерно, а кнопку нуля легко растянуть на несколько колонок без дополнительных узлов-оберток.

**Фрагмент кода (Реализация сетки кнопок в CSS):**

```css
/* Контейнер для кнопок калькулятора */
.buttons {
    display: grid;
    /* Создание 4 равных колонок */
    grid-template-columns: repeat(4, 1fr);
    gap: 8px; /* Стандартизированный отступ между кнопками */
}

/* Кнопка нуля растягивается на 2 колонки */
.my-btn.zero {
    grid-column: span 2;
}
```

### 4.3. Переворот калькулятора (CSS Transform)

**Теория:** Свойство `transform` в CSS позволяет применять различные пространственные трансформации к элементу: масштабирование, сдвиг, искажение и поворот. Для выполнения дополнительного задания была использована функция `rotate()`, которая поворачивает HTML-узел вместе со всем его содержимым на заданный угол вокруг точки трансформации (по умолчанию — центр элемента).

**Фрагмент кода (Применение трансформации в CSS):**

```css
/* Поворот основного блока калькулятора "вверх ногами" */
.calculator {
    /* ... прочие визуальные свойства ... */
    transform: rotate(180deg);
}

/* Опциональная инверсия текста внутри кнопок и экрана для сохранения читаемости */
.my-btn, .result {
    transform: rotate(180deg);
}
```
